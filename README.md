# Muster

**Muster turns defence contracts into work and workers for small Canadian factories.**

Status: hackathon build in progress (AF Hacks, Sept 2026)

## Quick start

```bash
make setup       # Python 3.12 venv via uv + engine deps (+ web deps if present)
make dev         # engine on :8000 and web on :3000
make demo-check  # verify the demo path end to end
```
